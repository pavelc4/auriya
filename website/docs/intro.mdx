# Auriya Wiki

Auriya is an Android root module composed of a Kotlin/Compose manager, an Android companion service, and a Rust daemon. This wiki documents how those components start, communicate, observe the system, and apply configuration.

## Documentation status

Every page is **source-traced**: behavioral claims cite the file (and often the
function) they come from, and each reference/internals page ends with a "Likely
to drift first" note listing what to re-verify when the code changes.

:::note Configuration is fully wired
Every `settings.toml` key the manager app writes is now consumed by the daemon —
the earlier Frame-Aware Scheduling scaffolding (`[fas]`, `[dynamic_governor]`,
`[modes.*]`, `check_interval_ms`) has been wired in. The
[settings reference](reference/settings#key-by-key-reference) documents each key's
effect and whether it applies live or only at daemon restart.
:::
